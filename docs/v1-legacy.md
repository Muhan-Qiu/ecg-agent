# V1.0 版本说明（随机森林）

V1.0 是项目的初版，完整代码与原始 README 保留在 tag：

<https://github.com/Muhan-Qiu/ecg-agent/tree/v1.0.0>

本页说明 V1.0 是什么、当时的结果、以及如何在当前代码中继续使用 V1.0 分类器。

## 1. V1.0 是什么

- **LLM Agent + 5 个本地工具**：`list_records`、`check_quality`、`measure`、
  `classify`、`lookup_guideline`。
- **分类器**：RandomForest，200 棵树，49 维特征，逐搏独立分类。
- **R 峰**：neurokit2 自动检测，不依赖专家标注。
- **输入**：MIT-BIH 记录，或实验设备/手表的单列 CSV。
- **界面**：中英双语 Streamlit，支持导出报告。

## 2. V1.0 的评测结果（原口径）

V1.0 在 DS2 测试集上评估 48,751 个自动检测心搏：

| 类别 | 精确率 | 召回率 | F1 |
|---|---:|---:|---:|
| N 正常搏动 | 0.948 | 0.994 | 0.971 |
| S 室上性异位 | 0.686 | 0.039 | 0.074 |
| V 室性异位 | 0.935 | 0.904 | 0.919 |
| F 融合搏动 | 0.033 | 0.008 | 0.013 |
| **总体准确率** | | | **94.5%** |

V1.0 的特征消融（S 召回 / V 召回 / 总体准确率）：

| 使用的特征 | S 召回 | V 召回 | 总体准确率 |
|---|---:|---:|---:|
| 仅 RR 间期特征 | 0.070 | 0.755 | 0.918 |
| 仅波形形态特征 | 0.008 | 0.816 | 0.927 |
| 全部特征 | 0.039 | 0.904 | 0.945 |

> **不要和 V2.0 直接对比。** V1.0 使用 49 维特征和自动检测 R 峰，评估 48,751 个检测心搏；
> V2.0 使用 104 维特征与标注/检测 R 峰，评估 49,024 个标注对齐心搏。两者特征、检测管线
> 和评估 beat 集不同。V2.0 的公开综合评分见项目首页 README。

## 3. 如何在当前代码中使用 V1.0

- 命令行：`T.classify_beats(record, engine="fallback")`
- 界面：分类模型选择“随机森林（回退）”
- 重新训练：`python train_classifier.py`
- 权重：`models/beat_classifier.pkl`
- 训练脚本：`train_classifier.py`
- 特征与工具：`ecg_tools.py`

## 4. V1.0 的主要限制

1. S 类召回只有 3.9%：室上性异位与正常搏动的 QRS 形态几乎相同，需要 P 波信息，
   而 V1.0 的 49 维特征里没有 P 波。
2. F 类召回只有 0.8%：全库样本极少，本身难以训练。
3. 分类器在 MIT-BIH 的 MLII 导联上训练；更换导联、采样率或设备增益会掉点。
4. 算法初筛，不是医疗器械，不能用于临床决策。
